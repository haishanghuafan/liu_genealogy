# 系统初始化脚本说明文档

## 概述

系统初始化脚本用于快速创建完整的演示数据，包括用户、租户、权限、角色、族谱数据等，适用于开发环境测试和功能验证。

## 脚本位置

```
backend/app/scripts/init_demo_data.py
```

## 使用方法

### 前置条件

1. 确保后端服务未运行（脚本会创建新数据库）
2. 确保已安装所有依赖

### 执行步骤

```bash
# 1. 进入后端目录
cd backend

# 2. 停止后端服务（如果正在运行）
# 按 Ctrl+C 停止 uvicorn 进程

# 3. 删除旧数据库（可选，如需重新初始化）
Remove-Item "genealogy.db" -Force -ErrorAction SilentlyContinue
Remove-Item "tenants" -Recurse -Force -ErrorAction SilentlyContinue

# 4. 执行初始化脚本
.\venv\Scripts\python.exe -m app.scripts.init_demo_data

# 5. 启动后端服务
.\venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8012
```

## 常见问题

### Q: 脚本执行失败，提示表已存在？

A: 删除旧数据库后重新执行：
```bash
Remove-Item "genealogy.db" -Force
Remove-Item "tenants" -Recurse -Force
.\venv\Scripts\python.exe -m app.scripts.init_demo_data
```

### Q: 脚本执行成功但后端服务报错？

A: 确保后端服务已重启，使用新数据库：
```bash
# 停止旧服务（Ctrl+C）
# 重新启动
.\venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8012
```

### Q: 如何修改初始化数据？

A: 编辑 `backend/app/scripts/init_demo_data.py` 文件，修改对应的数据创建逻辑。

### Q: 如何添加更多测试数据？

A: 在 `init_tenant1_data` 或 `init_tenant2_data` 函数中添加更多 Person 对象创建逻辑。

## 注意事项

1. **仅用于开发环境**: 此脚本仅适用于开发和测试，生产环境应使用正式的迁移脚本
2. **数据覆盖**: 执行脚本会清空现有数据并重新创建
3. **密码安全**: 演示账号密码仅用于开发环境，生产环境必须使用强密码
4. **数据库路径**: SQLite 数据库文件位于 `backend/genealogy.db` 和 `backend/tenants/` 目录
